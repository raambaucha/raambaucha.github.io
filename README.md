# Ram Parajuli — Personal Portfolio

A responsive, static personal portfolio website designed for GitHub Pages.

## Files

- `index.html` — website content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation
- `assets/` — CV and future images

## Before publishing

1. Replace `your.email@example.com` in `index.html` with your email.
2. Replace the LinkedIn URL with your actual LinkedIn profile.
3. Upload your CV to `assets/Ram-Parajuli-CV.pdf`.
4. Optional: replace the `RP` placeholder with your professional photo.

## GitHub Pages

Create a public repository named:

`YOUR-GITHUB-USERNAME.github.io`

Upload all files from this folder to the repository, then enable:

Settings → Pages → Deploy from a branch → `main` → `/ (root)`

Your website will be available at:

`https://YOUR-GITHUB-USERNAME.github.io`
